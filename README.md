# ⚽ 足球游戏 (Football Game)

一个基于 **Godot 4.3** 的俯视角足球游戏，支持单机对战和局域网联机。视角参考「最佳球会」的斜俯视3D视角。

## ✨ 功能特性

### 已实现（v0.1 Alpha）
- ✅ **主菜单** — 快速比赛、玩家档案、设置、局域网联机
- ✅ **本地玩家档案** — 教练名、等级、金币、比赛统计、生涯数据
- ✅ **3D球场** — 标准 FIFA 尺寸球场 (105m × 68m)，含草地纹理和标线
- ✅ **两支队伍** — 红队 vs 蓝队，各 11 人 (4-4-2 阵型)
- ✅ **完整动作系统** — 移动、传球、射门、抢断、冲刺、切换球员
- ✅ **比赛判定** — 计时、比分、进球判定、出界判定（球门球/角球）
- ✅ **基础电脑 AI** — 三层架构（球员AI + 球队战术 + 活动修正）
- ✅ **完整比赛流程** — 开球 → 上半场 → 中场休息 → 下半场 → 终场
- ✅ **本地存档** — JSON 格式，完全不依赖互联网
- ✅ **局域网联机框架** — 房主权威模式，房间码系统（已预留接口）

## 🎮 操作方式

### 键盘操作（当前支持）
| 按键 | 功能 |
|------|------|
| `W` `A` `S` `D` / 方向键 | 移动当前球员 |
| `空格` | 射门 |
| `J` | 传球 |
| `U` | 直塞球 |
| `K` | 切换控制球员 |
| `L` | 抢断 |
| `Shift` | 冲刺 |
| `ESC` | 暂停 |

### 触屏操作（计划中）
- 左侧虚拟摇杆：移动
- 右侧按钮：传球 / 射门 / 冲刺 / 切换

## 🏗️ 技术架构

### 引擎选择：Godot 4.3
- 开源免费，无需许可费用
- 内置 3D 渲染、物理、UI、动画、网络
- 支持 Android/iOS 导出
- GDScript 语法简单，适合零经验开发者

### 三层 AI 架构

```
┌─────────────────────────────────────────┐
│  第三层：活动修正 (Event Modifiers)       │
│  - 指定球员必须进球                       │
│  - AI不能进入特定区域                     │
│  - 对手最后几分钟全力防守                 │
│  - 限制射门次数 / 多球 / 加时 / 点球      │
├─────────────────────────────────────────┤
│  第二层：球队战术 (TeamAI)                │
│  - 进攻 / 平衡 / 防守                    │
│  - 高位逼抢 / 退守 / 快速反击             │
│  - 短传 / 长传 / 边路进攻                 │
│  - 领先控制节奏 / 落后增加压迫            │
├─────────────────────────────────────────┤
│  第一层：球员AI (PlayerAI)                │
│  - 接近球 / 选择站位                      │
│  - 传球 / 射门 / 抢断                     │
│  - 避开队友和边界                         │
│  - 回到所属区域                           │
└─────────────────────────────────────────┘
```

### 局域网联机架构（房主权威模式）

```
房主设备                          加入设备
├─ 运行比赛规则                    ├─ 发送操作输入
├─ 控制 AI                        ├─ 接收并显示房主状态
├─ 判定碰撞、进球和比分
└─ 向其他设备同步比赛状态
```

**安全策略：**
- 仅允许局域网地址 (192.168.x.x / 10.x.x.x / 172.16-31.x.x)
- 不接入官方服务器或任何公网服务
- 不做账号注册
- 不自动打开路由器端口
- 房间使用四位房间码
- 单机模式不启动网络监听

## 🚀 快速开始

### 环境要求
- [Godot 4.3](https://godotengine.org/download/) 或更高版本
- 无需安装任何 SDK 或依赖

### 运行项目
1. 下载并安装 Godot 4.3
2. 打开 Godot，点击「导入」
3. 选择本项目目录下的 `project.godot` 文件
4. 点击右上角 ▶ 播放按钮即可运行

### 导出为手机应用
1. 在 Godot 中点击「项目」→「导出」
2. 添加 Android 或 iOS 平台
3. 配置签名和包名
4. 点击「导出项目」
