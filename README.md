# ⚽ 足球游戏 (Football Game)

[![Build](https://github.com/xf8410/football-game/actions/workflows/build.yml/badge.svg)](https://github.com/xf8410/football-game/actions/workflows/build.yml)
[![Release](https://img.shields.io/github/v/release/xf8410/football-game)](https://github.com/xf8410/football-game/releases)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Godot](https://img.shields.io/badge/Godot-4.3-478CBF.svg)](https://godotengine.org)

一个基于 **Godot 4.3** 的俯视角足球游戏，支持单机对战和局域网联机。视角参考「最佳球会」的斜俯视3D视角。

## 📦 下载安装

### Android
1. 前往 [Releases页面](https://github.com/xf8410/football-game/releases)
2. 下载 `football-game.apk`
3. 安装到手机（需允许"未知来源"安装）

### Windows
1. 前往 [Releases页面](https://github.com/xf8410/football-game/releases)
2. 下载 `FootballGame.exe`
3. 双击运行

### 从源码构建
```bash
# 克隆仓库
git clone https://github.com/xf8410/football-game.git

# 下载 Godot 4.3
# 打开项目目录下的 project.godot
# 点击运行按钮即可
```

## 🏗️ 技术架构

### 引擎选择：Godot 4.3
- 开源免费，无需许可费用
- 内置 3D 渲染、物理、UI、动画、网络
- 支持 Android/iOS 导出
- GDScript 语法简单，适合零经验开发者

### 三层 AI 架构

```
┌─────────────────────────────────────────┐
│  第三层：活动修正 (Event Modifiers)       │
│  - 指定球员必须进球                       │
│  - AI不能进入特定区域                     │
│  - 对手最后几分钟全力防守                 │
│  - 限制射门次数 / 多球 / 加时 / 点球      │
├─────────────────────────────────────────┤
│  第二层：球队战术 (TeamAI)                │
│  - 进攻 / 平衡 / 防守                    │
│  - 高位逼抢 / 退守 / 快速反击             │
│  - 短传 / 长传 / 边路进攻                 │
│  - 领先控制节奏 / 落后增加压迫            │
├─────────────────────────────────────────┤
│  第一层：球员AI (PlayerAI)                │
│  - 接近球 / 选择站位                      │
│  - 传球 / 射门 / 抢断                     │
│  - 避开队友和边界                         │
│  - 回到所属区域                           │
└─────────────────────────────────────────┘
```

### 局域网联机架构（房主权威模式）

```
房主设备                          加入设备
├─ 运行比赛规则                    ├─ 发送操作输入
├─ 控制 AI                        ├─ 接收并显示房主状态
├─ 判定碰撞、进球和比分
└─ 向其他设备同步比赛状态
```

**安全策略：**
- 仅允许局域网地址 (192.168.x.x / 10.x.x.x / 172.16-31.x.x)
- 不接入官方服务器或任何公网服务
- 不做账号注册
- 不自动打开路由器端口
- 房间使用四位房间码
- 单机模式不启动网络监听

## 🚀 快速开始

### 环境要求
- [Godot 4.3](https://godotengine.org/download/) 或更高版本
- 无需安装任何 SDK 或依赖

### 运行项目
1. 下载并安装 Godot 4.3
2. 打开 Godot，点击「导入」
3. 选择本项目目录下的 `project.godot` 文件
4. 点击右上角 ▶ 播放按钮即可运行

### 导出为手机应用
1. 在 Godot 中点击「项目」→「导出」
2. 添加 Android 或 iOS 平台
3. 配置签名和包名
4. 点击「导出项目」
